## 项目定位

DSH Bridge 是一个为 DeepSeek Harness 提供多通道访问能力的生产级插件，与 cloudflared 共存而非替代，提供更完整的远程访问解决方案。

## 核心功能

### 访问层
1. **局域网访问**
   - 智能网络接口检测
   - 二维码快速访问
   - LRU + TTL 缓存优化

2. **Cloudflare 隧道**
   - 自动下载二进制
   - 跨平台支持
   - 一键启停

3. **自建隧道**
   - WebSocket 反向隧道
   - Token 认证
   - 指数退避重连
   - 心跳监控

### 扩展层（规划中）
- 微信机器人（Clawbot）
- QQ 机器人
- Telegram 机器人
- 飞书机器人
- Slack/Discord 集成

## 技术架构

### 核心组件
- **ProxyServer**: HTTP/WebSocket 代理服务器
- **BridgeService**: 服务编排和状态管理
- **CustomTunnelClient**: WebSocket 隧道客户端
- **CloudflaredManager**: Cloudflared 生命周期管理
- **QrCache**: 二维码 LRU 缓存

### 技术栈
- **运行时**: Node.js 18+
- **插件框架**: Cordis
- **WebSocket**: ws
- **二维码**: qrcode
- **前端**: React
- **容器化**: Docker

## 常见问题

### Q: 与 cloudflared 是什么关系？
A: 共存关系。DSH Bridge 提供三种访问方式，cloudflared 是其中之一。同时提供自建隧道和局域网访问作为补充。

### Q: 为什么需要自建隧道？
A: 生产环境需要稳定的域名、数据控制和可审计性，自建隧道提供这些能力。

### Q: 如何选择访问方式？
A: 
- 局域网：同一 Wi-Fi，零配置
- Cloudflare：快速演示，临时分享
- 自建隧道：生产环境，长期使用

### Q: 安全性如何保障？
A: Token 认证、Loopback-only RPC、Host Header 重写、HTTPS/WSS 加密。
